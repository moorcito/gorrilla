# gorrilla

[English](README.md) · **Español**

Una aplicación web para que una comunidad comparta sus plazas de aparcamiento
igual que los equipos comparten los puestos flexibles (*hot desks*) en la
oficina: reservas una plaza para los días que la necesitas.

Una plaza puede pertenecer a alguien, que decide primero: solo entra en el
reparto los días en que esa persona no la va a usar.

Cuando hay más solicitudes que plazas libres, un reparto semanal da prioridad
a quien menos ha aparcado en los últimos meses. El resto pasa a una lista de
espera, y quien esté primero en la cola se queda con la siguiente plaza que se
libere.

El nombre viene del gorrilla, que te indica dónde hay sitio para aparcar.

> [!WARNING]
> Es un proyecto de aprendizaje: lo estoy haciendo para aprender Python y
> Django, con ayuda de Claude, el asistente de IA de Anthropic. Revisa el
> código antes de fiarte de él.

**Estado:** primeras fases de desarrollo.
